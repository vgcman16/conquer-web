# Original Jade Realm artwork

These assets were generated for this project with the built-in OpenAI image-generation tool. They contain no extracted Conquer Online textures, meshes or interface graphics. Prompts asked for original premium hand-painted ancient Chinese wuxia RPG art with a consistent warm light source and isometric camera.

| File              | Production prompt brief                                                                                                                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| temple.png        | One isolated Chinese martial academy temple; two-tier curved jade tile roofs, gold dragon ornaments, red carved timber, ivory plaster, lanterns, mossy stone foundation; orthographic 2:1 view and transparent surroundings. |

The renderer frames assets at runtime and scales them to the logical world. World players use `body.png` with separate equipment sprites from `equipment.png`; material variants recolor the pieces while preserving shading. Procedural weapon geometry supplies additional models such as bows, staffs, spears, daggers, orbs and quivers. Necklaces draw a small pendant, and glow descriptors add restrained aura effects. The inventory preview is extracted from the same equipped avatar.

The character atlas remains in use for NPCs and humanoid monsters. Hero artwork remains available for illustration and fallback rendering. Movement uses procedural sprite transforms, including independent cape motion. Rigged 3D meshes and skeletal animation remain a separate future milestone.

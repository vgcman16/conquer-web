# Original Jade Realm artwork

These assets were generated for this project with the built-in OpenAI image-generation tool. They contain no extracted Conquer Online textures, meshes or interface graphics. Prompts asked for original premium hand-painted ancient Chinese wuxia RPG art with a consistent warm light source and isometric camera.

| File              | Production prompt brief                                                                                                                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| temple.png        | One isolated Chinese martial academy temple; two-tier curved jade tile roofs, gold dragon ornaments, red carved timber, ivory plaster, lanterns, mossy stone foundation; orthographic2:1view and transparent surroundings. |
| tree-v2.png       | Detailed isolated ginkgo trunk and jade foliage; remove the first version's background haze/glow; retain only natural foliage, roots and on-object lighting.                                                               |
| hero.png          | Full-body adult dual-sword fighter in jade lamellar armor, antique gold trim, navy cape, red sash; realistic proportions, transparent surroundings.                                                                        |
| gate.png          | An open red timber paifang gate with jade tile roof, gold ornaments, lanterns and mossy stone bases; transparent center and surroundings.                                                                                  |
| pheasant.png      | Ring-necked pheasant with copper/emerald feathers and long tail; accurate anatomy, down-left isometric view, isolated silhouette.                                                                                          |
| icons.png         | Exact3×2painted atlas: dual swords, golden dragon skill, blue aerial leap, red healing flask, jade-sealed scroll and leather bag; no labels.                                                                               |
| characters-v2.png | Exact3×2atlas: Trojan, Warrior, Archer, Fire Taoist, Water Taoist, elderly unarmed scholar; adult proportions, full-body, equal frame scale and isolated silhouettes; follow-up background-removal pass.                   |

The renderer frames assets at runtime and scales them to the logical world. Current character art uses static directional sprites with procedural movement. Rigged meshes and skeletal animation remain a separate future milestone.
